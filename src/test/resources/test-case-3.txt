Заголовок: Проверка авторизации с данными из файла (позитивный и негативный сценарии).

Предусловие: 
Открыта страница авторизации https://www.saucedemo.com/

Тестовые данные (из файла login_data.csv):
- standard_user (валидный)
- locked_out_user (заблокированный)

Шаги:
1. Ввести незаблокированный логин в поле "Username".
2. Ввести пароль "secret_sauce" в поле "Password".
3. Нажать кнопку "Login".
4. Повторить шаги 1-3 для каждого набора данных из файла.

Ожидаемый результат:
1. Для валидного пользователя (standard_user): 
Пользователь авторизован. Произошел редирект на страницу каталога товаров, отображается заголовок "Products".
2. Для заблокированного пользователя (locked_out_user): 
Пользователь остается на странице авторизации. В верхней части формы появляется красный блок с сообщением об ошибке - 
"Epic sadface: Sorry, this user has been locked out".
